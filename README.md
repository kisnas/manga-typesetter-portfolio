# Manga Typesetter Portfolio

A lightweight one-page portfolio made for manga typesetting / lettering work.

## Replace your sample images

The current page uses placeholders so it can be published immediately.

Recommended files:

- `assets/featured.webp`
- `assets/sample-01.webp`
- `assets/sample-02.webp`
- `assets/sample-03.webp`
- `assets/before.webp`
- `assets/after.webp`

For fast loading, export portfolio previews as WebP or optimized JPEG.

## Contact info

Edit these links near the bottom of `index.html`:

- Email
- Discord
- GitHub

## Publish on GitHub Pages

1. Open repository Settings → Pages.
2. Under Build and deployment, choose `Deploy from a branch`.
3. Branch: `main`, folder: `/ (root)`.
4. Save.

The page will be available at:

`https://kisnas.github.io/manga-typesetter-portfolio/`
